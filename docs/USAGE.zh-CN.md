# HorizonSync 使用说明

当前版本为开发预览版。请先测试，不要直接当作已完成真机验证的稳定版。

## 第一次设置

1. 打开“时间”，选择“日出日落（系统定位）”。每次启动会读取 Windows 当前日期、时间、时区和可用位置；有系统位置时直接采用，获取失败则保留原坐标并提示。第一次没有坐标时，需填写备用坐标。
2. 如果只希望使用固定坐标，选择“日出日落（指定坐标）”。南纬、西经用负数。纬度范围 -90～90，经度范围 -180～180。
3. 根据需要设置提前或延后分钟数，再点击“预览今日计划”。日落偏移 -20 表示日落前20分钟切换到夜晚壁纸。
4. 打开“壁纸”，程序会自动检测 Wallpaper Engine：正常运行显示绿色，已找到但未启动显示琥珀色，未找到显示红色。异常入口会直接跳转“设置与说明”中的程序位置；路径输入和手动浏览只在设置页。然后分别选择白天、夜晚壁纸。可从已安装库选择，也可在 Wallpaper Engine 中右键壁纸→在资源管理器中打开，再手动选文件。场景壁纸通常选 `project.json`，视频壁纸选视频文件，网页壁纸选 `index.html`。
5. 显示器编号从0开始。点击昼夜测试按钮，检查是否更换了正确屏幕。命令成功返回只表示已发送，首次仍需目视确认。
6. 在 Wallpaper Engine 保存原播放列表，并停用其固定时间切换，避免两套规则覆盖彼此。
7. 打开“启用自动壁纸切换”并点击“保存设置”。需要登录启动时，在“设置与说明”页打开对应开关，再保存。

## 浏览与预览壁纸

从已安装库选择时，使用名称搜索和缩略图网格浏览。点击卡片会打开居中大图，等比例显示项目预览；GIF 自动循环，普通图片保持静态。“暂停预览”会释放动态解码器并显示首帧，点击“播放预览”可恢复。大图展示标题、作者和项目编号。点击“使用这张壁纸”才会更新对应的白天或夜晚路径，仍需在主界面保存设置。

点击“返回浏览”、大图外的暗色区域或按 Esc 返回网格，再按 Esc 关闭选择窗口。方向键移动卡片焦点，Enter 打开大图；搜索框中的 Enter 不会提交选择。可以重新扫描本地库；未找到时也可返回使用文件浏览按钮。

仅当前大图播放 GIF。返回、最小化或关闭窗口时会停止并释放动态预览；恢复最小化窗口后重新加载。GIF 文件超过 16 MiB，或宽×高×4×帧数超过 64 MiB 时，显示静态首帧。图片损坏或格式不支持不影响选择。本轮不直接播放视频或渲染场景、网页壁纸。

网格按需加载并回收离屏卡片，静态图片缓存同时限制为 128 张和 24 MiB，关闭窗口时清空。动态帧不进入缓存。释放资源后，Windows 显示的进程内存不一定立刻下降。

有本地作者信息时直接显示；缺失时，仅为打开的大图向 Steam 查询壁纸作者 ID 和公开昵称。查询最长 10 秒，不上传壁纸、配置或坐标，不需要密钥。成功和失败结果在本次程序会话内缓存，失败后可点击“重试作者查询”；联网失败时显示已有作者 ID 或“作者未知”。昵称依赖 Steam 已弃用的社区 XML 接口，可能不可用。创意工坊详情和作者主页由用户点击后在浏览器中打开。

## 日常运行

- 每15秒检查当前状态，通常在切换时刻之后15秒内发送命令。
- 系统日期、时区变化会重新计算。程序使用系统时间，不校准或修改 Windows 本身的时钟。
- 系统位置在启动或点击“重新读取系统位置”时获取，不持续追踪；尊重现有定位权限，不自动修改权限。
- 关闭窗口后留在托盘。托盘菜单“彻底退出”后停止调度。睡眠期间不会切换，唤醒后重新判断。
- 界面修改需保存才生效。手动测试后，已启用的自动规则约30秒后重新对齐。

## 配置与恢复

安装版：`%LOCALAPPDATA%\HorizonSync`。便携版：程序旁的 `data` 文件夹。请保留 EXE 旁的 `.exe.config`，它用于渲染和运行配置。

`settings.xml` 保存设置，`settings.xml.bak` 是上次备份，`activity.log` 记录结果与错误。配置损坏时程序会停止自动切换；重新保存时会另存损坏原件。日志最多保留当前文件和一份轮转文件，单份约512KB。

要恢复原有壁纸安排，关闭登录启动并保存，从托盘退出 HorizonSync，再在 Wallpaper Engine 加载原播放列表。卸载默认保留用户配置；手动删除配置目录后才会清除已保存坐标和路径。

移动便携目录后，需要重新设置登录启动。当前版本每次管理一块屏幕，不自动替换或修改 Wallpaper Engine 的原始配置文件。
