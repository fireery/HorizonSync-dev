# HorizonSync identity

The owner approved this artistic monochrome mark and its vector reconstruction on 2026-10-31. The software and future GitHub project presentation use this same identity.

The mark is three closed curved silhouettes with a negative-space horizon. The SVG contains paths, not an embedded bitmap. Black and white exports share the same contour and proportions.

| Asset | Purpose |
| --- | --- |
| `assets/HorizonSync.svg` | Primary transparent vector |
| `assets/HorizonSync-Black.svg`, `HorizonSync-White.svg` | Contrast variants |
| `assets/HorizonSync-Black.png`, `HorizonSync-White.png` | Transparent 1024px PNGs |
| `assets/HorizonSync.ico` | Executable and installer icon |
| `assets/HorizonSync-Black.ico`, `HorizonSync-White.ico` | Nine resolutions from 16 to 256px; window/tray contrast variants |
| `assets/HorizonSync-GitHub.png` | Square 512px PNG for project presentation |
| `assets/brand/source-prompt.txt` | Exact generation prompt and mode |

These original project assets are included under the project's GPL-3.0-only license. The rejected colorful concepts are not application resources.

The approved concept was generated with the built-in image_gen tool and then redrawn as vector paths. Design comparison sheets and the draft raster concept are retained locally and excluded from the public repository and release source package. Public assets are the finalized mark and its application/GitHub exports.
